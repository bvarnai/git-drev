# Subcommand Technical Specification: `git-drev --help` / `help`

## 1. Subcommand Overview & CLI Contract
- **Invocation signatures:**
  - Root help flag: `git drev --help`, `git-drev -h`
  - Subcommand help flag: `git drev <subcommand> --help`, `git-drev <subcommand> -h`
  - Git plugin help positional: `git drev help [<subcommand>]`, `git-drev help [<subcommand>]`
- **Target Go package:** `internal/cli` (`root.go`)
- **Summary:** Prints command usage, description, available flags, and registered subcommands to `stdout` and exits `0`. Replaces the legacy behavior where positional `help` wrote to `stderr` and exited with failure (`1`).

## 2. Arguments, Flags & Routing
- **Positional arguments (`help` command):**
  - **Cardinality:** `0..1` argument specifying a registered subcommand name.
  - **Omitted:** Displays root command help listing all subcommands and global flags.
  - **Specified subcommand:** Displays the specific subcommand's usage, description, and flags.
  - **Unknown subcommand:** If an unrecognized subcommand name is passed (e.g. `git drev help foobar`), prints an unknown command error to `stderr` and exits with `errcode.ErrUsage` (`2`).

- **Preconditions & state assertions:**
  1. **Working directory independence:** Help commands execute anywhere on the host filesystem and do not require being inside a Git repository.
  2. **Configuration file independence:** Does not require `.git-drev.yaml` or any configuration files.

## 3. Output Contract & Exit Codes
- **Standard output (`stdout`):**
  - Formatted usage synopsis, description, and flag tables generated by Cobra.
  - Zero log prefixes (`[git-drev]`), ensuring clean formatting in terminal pagers (`man`, `less`).
- **Standard error (`stderr`):**
  - Clean (`0` bytes written) under normal execution.
  - Emits `[git-drev] Error: unknown command "<name>" for "git-drev"` when an unknown subcommand is queried.

| Exit Code | Go Error Category | Semantic Meaning | Scenario |
| :---: | :--- | :--- | :--- |
| `0` | `nil` | Success | Help text printed cleanly to `stdout`. |
| `2` | `errcode.ErrUsage` | Usage Error | Unknown subcommand passed to `help`. |
