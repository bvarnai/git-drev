# Subcommand Technical Specification: `git-drev completion`

## 1. Subcommand Overview & CLI Contract
- **Invocation signatures:**
  - Via Git plugin: `git drev completion [bash|zsh|fish|powershell] [flags]`
  - Direct binary: `git-drev completion [bash|zsh|fish|powershell] [flags]`
- **Target Go package:** `internal/cli` (`completion.go`)
- **Summary:** Generates dynamic shell autocompletion scripts for supported interactive shells (`bash`, `zsh`, `fish`, `powershell`), enabling tab-completion of `git-drev` subcommands, flags, branch names, and tags.

## 2. Arguments, Flags & Preconditions
- **Subcommand-specific flags:**
  | Flag | Short | Go Type | Default | Required | Description |
  | :--- | :--- | :--- | :--- | :--- | :--- |
  | *(None)* | — | — | — | — | `completion` accepts only the standard global flags (`--help`, `--no-color`, `--quiet`, `--verbose`). |

- **Positional arguments:**
  - **Cardinality:** Exactly `1` argument specifying the target shell: `bash`, `zsh`, `fish`, or `powershell`.
  - **Validation rules:**
    - Passing zero arguments or more than one argument fails immediately with `errcode.ErrUsage` (exit code `2`).
    - Passing an unrecognized shell argument (e.g., `tcsh`, `cmd`) fails immediately with `errcode.ErrUsage` (exit code `2`).

- **Preconditions & state assertions:**
  1. **Working directory independence:** Can be executed from any directory on the host filesystem; does **not** require being inside a Git repository.
  2. **Configuration file independence:** Does **not** require `.git-drev.yaml` or any environment configuration.

## 3. Dynamic Shell Completion Integration
- **Branch and tag autocompletion (`completeBranchNames`):**
  - Registered as the `ValidArgsFunction` for commands accepting ref arguments (`select`, `create`).
  - When invoked inside a Git repository, it calls `Inspector.ListAllBranchNames` and `Inspector.ListAllTags` to dynamically suggest:
    - All local branches (`refs/heads/*`).
    - All remote-tracking branches with `origin/` stripped.
    - All tags (`git tag -l`).
  - When invoked outside a Git repository, it returns `ShellCompDirectiveNoFileComp` without error to prevent polluting terminal completion.

## 4. Output Contract & Exit Codes
- **Standard output (`stdout`):**
  - Emits the raw shell script generated by Cobra (`GenBashCompletion`, `GenZshCompletion`, `GenFishCompletion`, `GenPowerShellCompletionWithDesc`).
  - Output contains zero diagnostic log prefixes, enabling safe piping into shell evaluators (e.g. `source <(git-drev completion bash)`).
- **Standard error (`stderr`):**
  - Clean under normal execution (`0` bytes written).
  - Emits `[git-drev] Error: <message>` on usage or validation errors.

| Exit Code | Go Error Category | Semantic Meaning | Scenario |
| :--- | :--- | :--- | :--- |
| `0` | `nil` | Success | Shell autocompletion script generated cleanly to `stdout`. |
| `2` | `errcode.ErrUsage` | Usage Error | Missing shell argument, unrecognized shell, or too many arguments. |
